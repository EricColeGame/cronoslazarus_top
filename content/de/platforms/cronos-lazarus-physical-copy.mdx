## Was Cronos: Lazarus zu bieten hat

Bevor Sie sich auf die Jagd nach Discs begeben, hilft es zu wissen, was genau Sie ins Regal stellen würden. Cronos: Lazarus setzt die Geschichte der Ödländer von New Dawn fort, dreht aber die Perspektive um. Sie spielen den einst loyalen Pathfinder, der langsam zum Warden wird — isoliert im Terminal, abgeschnitten vom Collective und besessen davon, eine verlorene Essence wiederzubeleben, die er nicht loslassen will.

Das Gameplay verändert sich mit der Figur. Wo das Basisspiel Geduld, Positionierung und die sorgfältige Wahl der Kämpfe belohnte, setzt die Erweiterung auf Aggression. Sie erhalten Werkzeuge, die einem Pathfinder vorbehalten sind: Köder, die Sie zurücklassen können, um Verfolger in die Irre zu führen, und die Fähigkeit, vorübergehend unsichtbar zu werden. Diese Fähigkeiten gibt es aus gutem Grund — ein Jäger, der speziell dafür konstruiert wurde, Sie zu eliminieren, ist Ihnen auf den Fersen, und die Begegnungen steigern sich zu großen, filmreifen Kämpfen.

- **Tonwechsel:** schnellerer, aggressiverer Kampf als im Basisspiel
- **Neue Fähigkeiten:** Köder, vorübergehende Unsichtbarkeit, verbesserte Fortbewegung
- **Neuer Antagonist:** ein unerbittlicher, anpassungsfähiger Verfolger, der dem Warden gewachsen ist
- **Handlungsstrang:** Fragmente aus der Vergangenheit des Warden und das Lazarus-Protokoll selbst

## Ist eine physische Kopie von Cronos Lazarus derzeit erhältlich?

Zum Zeitpunkt dieses Textes ist der einzige bestätigte Ort, an dem die Erweiterung gekauft werden kann, digital. Die offizielle [Cronos: Lazarus-Seite im Epic Games Store](https://store.epicgames.com/p/cronos-the-new-dawn-cronos-lazarus-3ea331) ist der Referenzpunkt; dort wird die Erweiterung als Download verkauft, der an Ihr Konto gebunden ist — keine Disc-SKU, keine Handelsbox, keine angekündigte Collector's Edition.

Das bedeutet nicht, dass es niemals eine physische Kopie von Cronos Lazarus geben wird. Es bedeutet, dass niemand eine angekündigt hat und dass jeder, der Ihnen heute eine „versiegelte Disc" verkauft, entweder einen Platzhalter, einen Code in einer Box oder etwas verkauft, das nicht dem entspricht, was das Angebot behauptet.

Der nützliche Teil: Erweiterungen erreichen physische Datenträger fast immer in einer von wenigen vorhersehbaren Formen. Sollte eine physische Kopie von Cronos Lazarus erscheinen, wird sie höchstwahrscheinlich wie eine der folgenden aussehen.

| Format, das Sie finden könnten | Was wirklich drin ist | Basisspiel erforderlich? | Realistisch für Cronos: Lazarus? |
|---|---|---|---|
| Eigenständige Erweiterungs-Disc | Eine Disc, die nur den Erweiterungsinhalt enthält | Meist ja | Unbestätigt — keine angekündigte SKU |
| Complete-/All-in-Edition-Disc | Basisspiel plus Erweiterung auf einer Disc | Nein | Später möglich; nichts angekündigt |
| Basisspiel-Disc + Gutscheincode | Handelsdisc mit einem Papier-Downloadcode im Inneren | Ja | Gängiges Branchenmuster; hier unbestätigt |
| Collector's Box mit Code | Steelbook, Artbook oder Statue plus ein Code | Ja | Hängt ganz von den Plänen des Publishers ab |
| „Physische" PC-Box | Eine Box mit einem Key, keine Disc | Ja | Auf dem PC häufig — lesen Sie das Kleingedruckte |

Die Lektion: „Physisch" ist ein Wort, das Händler locker verwenden. Bestätigen Sie immer, dass eine Disc enthalten ist, bevor Sie annehmen, dass Sie eine physische Kopie von Cronos Lazarus kaufen.

## Plattformen und Formate: Wo eine physische Kopie von Cronos Lazarus landen könnte

Die Plattform ist wichtiger, als die meisten Käufer erwarten. Konsolen bekommen noch echte Discs; der PC-Einzelhandel ist weitgehend zu Code-in-a-Box geworden. Sollte jemals eine physische Kopie von Cronos Lazarus erscheinen, sind die Konsolenversionen diejenigen, die man im Auge behalten sollte.

| Plattform | Wie das Basisspiel üblicherweise verkauft wird | Chancen auf eine physische Kopie von Cronos Lazarus | Worauf zu achten ist |
|---|---|---|---|
| PlayStation 5 | Disc und digital | Mittel — Konsolen-Erweiterungen bekommen später oft gebündelte Discs | „Complete Edition"-Angebote, ESRB- vs. PEGI-Cover |
| Xbox Series X | Disc und digital | Mittel | Smart-Delivery-Kennzeichnungen, Regionsvarianten |
| PC (Einzelhandel) | Digitale Keys; Codes in Boxen | Gering für eine echte Disc | Boxen mit der Aufschrift „Download-Code" oder „keine Disc enthalten" |
| Cloud / Streaming | Nur digital | Sehr gering | Streaming-Zugang ist niemals eine Disc |

Ein paar praktische Hinweise, die Zeit sparen:

- Konsolen-Discs sind in der Regel regionsfrei, aber DLC-Berechtigungen können dennoch an die Region des Kontos gebunden sein, das sie einlöst.
- Eine Disc aus einer anderen Region lässt sich möglicherweise problemlos installieren und verweigert dennoch Erweiterungsinhalte, die an einen anderen Store gebunden sind.
- „Physische" PC-Veröffentlichungen sind die häufigste Enttäuschungsquelle — die Box ist echt, die Disc meist nicht.

Wenn Ihr Ziel einfach ist, Cronos: Lazarus heute zu spielen, ist der digitale Weg der einzige bestätigte. Wenn Ihr Ziel das Sammeln ist, ändert sich die Rechnung. Hier ist der ehrliche Vergleich.

| Faktor | Digital (Epic Games Store) | Physische Disc |
|---|---|---|
| Heute bestätigte Verfügbarkeit | Ja | Keine eigenständige SKU angekündigt |
| Zeit von Kauf bis zum Spielen | Minuten | Abhängig von Bestand und Versand |
| Weiterverkauf oder Verleihen | Nicht möglich | Möglich, wo Discs existieren |
| Regal- und Sammlerwert | Gering | Hoch |
| Abhängigkeit von Patches | Erfordert einen Download | Disc installiert, benötigt aber möglicherweise trotzdem Patches |
| Kontoanforderungen | An Ihr Store-Konto gebunden | Disc installiert; Erweiterungsberechtigung kann dennoch kontobasiert sein |
| Risiko eines falsch deklarierten Kaufs | Sehr gering | Höher — siehe Checkliste unten |

Für die meisten Spieler gewinnt die digitale Version bei der Bequemlichkeit. Für Sammler ist das Warten der Preis des Eintritts. Keine der beiden Entscheidungen ist falsch — sie beantworten nur unterschiedliche Fragen.

### Warnsignale, die man sich merken sollte

Berichte aus der Community von Disc-Sammlern folgen einem vorhersehbaren Muster: Die Angebote, die Leute reinlegen, sind selten offensichtliche Betrügereien — sie sind einfach vage. Nutzen Sie diese Checkliste, bevor Sie sich festlegen.

| Prüfpunkt | Gutes Zeichen | Warnsignal |
|---|---|---|
| Produktfoto | Echte Disc, Hülle und Altersfreigabe-Logo | Stock-Render ohne gezeigte Hülle |
| Formulierung der Beschreibung | „Enthält Disc" oder „Disc-Version" | „Digitale Lieferung", „nur Code", „keine Disc" |
| Preis | Im Einklang mit vergleichbaren Handelsdiscs | Dramatisch unter allen anderen Angeboten |
| Verkäuferhistorie | Lange Erfolgsbilanz mit Bewertungen | Ganz neues Konto, keine Bewertungen |
| Regionsangabe | Klare ESRB-, PEGI- oder CERO-Kennzeichnung | Vage „Import"-Sprache ohne genannte Region |
| Plattformkennzeichnung | Expliziter Plattformname auf der Box | Allgemeine „Konsole"-Formulierung |

Wenn ein Verkäufer die Frage „Ist eine Disc in der Box?" nicht in einem Satz beantworten kann, gehen Sie weg. Diese eine Frage filtert die meisten gefälschten Angebote für eine physische Kopie von Cronos Lazarus heraus.

Unbekannt, da keine Disc-Version angekündigt wurde. Basierend darauf, wie Erweiterungen üblicherweise erscheinen, würde eine eigenständige Disc wahrscheinlich trotzdem Cronos: The New Dawn zum Spielen erfordern, während eine Complete-Edition-Disc beides bündeln würde. Lesen Sie immer den Text auf der Box, bevor Sie etwas annehmen.

### Kann ich eine physische Kopie von Cronos Lazarus weiterverkaufen oder verleihen?

Wenn eine Disc-Version existiert, funktionieren Weiterverkauf und Verleihen im Allgemeinen so wie bei jedem Konsolenspiel. Digitale Käufe können nicht weiterverkauft oder verliehen werden, was einer der stärksten Gründe ist, warum Sammler weiter auf eine physische Kopie von Cronos Lazarus warten, statt einen Download zu kaufen.

### Wie vermeide ich gefälschte Angebote für eine „physische Kopie"?

Stellen Sie drei Fragen: Zeigt das Foto eine Disc, sagt die Beschreibung „Disc enthalten", und trägt die Box eine sichtbare Altersfreigabe? Wenn eine Antwort nein lautet, behandeln Sie es als Code-in-a-Box-Produkt. Die Spielererfahrung in Sammler-Communities ist diesbezüglich einheitlich — das günstigste Angebot ist fast immer das, das keine Disc ist.

Das Fazit: Eine physische Kopie von Cronos Lazarus ist noch nicht bestätigt, aber die Erweiterung selbst ist real, aggressiv und es wert, gespielt zu werden, egal wie Sie sie bekommen. Kaufen Sie digital, wenn Sie diese Woche spielen wollen. Warten Sie und prüfen Sie, wenn Sie sie im Regal haben wollen — und vertrauen Sie niemals einem Angebot, das Ihnen die Disc nicht zeigt.
